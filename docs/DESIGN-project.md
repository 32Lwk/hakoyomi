# DESIGN

詳細UIは `/workspace/contests/bwc_japan_2026/docs/design.md` を一次参照。

## Do
- 箱起点（症状入力なし）。登販が画面を見て客に口で伝える
- 差分は「違う」の1色のみ。原文は箱の文言引用
- 「判断は販売者が行ってください」常時表示
- 各情報に出典（PMDA／製品公式のどの欄か）を画面で明示
- 販売記録作成支援（確認事実・時刻・担当仮名のみ。客の健康情報は持たない）
- Claude＝読む・揃える・照らす・自己検査。数値換算・差分・8成分一次判定はコード
- スライドは1画面1メッセージ（テンプレ感を嫌う）

## Don't
- 医療アドバイス／症状→OTC推奨／効く・量が多い＝効く／おすすめ・代わりにこれ
- 緑赤の良し悪し色、量順ソート、販売可ボタン
- MedNavi・道場の再利用、客向けモード
- 客の健康PII保存
- 「病気がわかる」「診断できる」等、医療機器（SaMD）該当を思わせる説明・宣伝文言
- 添付文書全文の公開再配布・一括クロール（PMDAはリンクアウト主）
