# DESIGN

詳細UIは `design.md`（同じ docs/ 内）を一次参照。本ファイルはプロジェクトの Do/Don't の補足。改訂 2026-11-02（L-20261102-32）。

## Do
- JAN起点＋質問起点。登販が画面を見て、お客様に自分の言葉で伝える
- 場面ごとに画面を分ける（読む／比べる／さがす／棚）。1回の操作は数秒〜十数秒
- バッジで一目で分かるように。タップで根拠（通知の項目と記載条件、成分と分量、禁止表の年版）
- 差分は「違う」の1色のみ
- 「判断は販売者が行ってください」常時表示。逆引き結果には「この中から選ぶのは販売者です」
- すべての表示に出典。通知由来の表示には「実際の添付文書は PMDA で確認」
- Claude＝役割分担のエージェント（解釈・検索・照合・出典検証・ガード）、逆引きの対応づけ、販売記録の下書き。回答は抜き出しのみ。数値換算・差分・記載条件の評価・8成分判定・禁止表照合はコード
- ベテランの説明メモを新人が引ける形に
- スライドは1画面1メッセージ（テンプレ感を嫌う）

## Don't
- おすすめ・順位付け・代わりにこれ・効く・量が多い＝効く
- 個人の病状・受診要否・販売可否の判定、用法の個人計算
- 緑赤の良し悪し色、量順ソート、販売可ボタン、「眠気なし」のような安心させるバッジ
- 客向けモード、お客様の症状・氏名・健康情報の保存
- 「病気がわかる」「診断できる」等、医療機器（SaMD）該当を思わせる説明・宣伝文言
- 商品固有の添付文書本文の表示・保存・再配布、一括クロール、実行時の PMDA 自動アクセス
- 既存プロジェクト（MedNavi・道場）のコードの再利用。データは L-40 の範囲（demoSkus.json）だけ
- 製品画像の取得・保管（例外：ゆうが取得したデモSKUのパッケージ写真を images.yutok.dev から表示、L-40）
