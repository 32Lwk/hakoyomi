# DESIGN

詳細UIは `design.md`（同じ docs/ 内）を一次参照。本ファイルはプロジェクトの Do/Don't の補足。

## Do
- JAN起点（症状入力なし）。登販が画面を見て客に口で伝える
- 差分は「違う」の1色のみ。添付文書の文言は画面に出さず、欄名・改訂日・PMDAリンクで登販が原文を確認
- 「判断は販売者が行ってください」常時表示
- 各情報に出典（PMDA 添付文書のどの欄か・改訂日）を画面で明示
- 販売記録作成支援（確認事実・時刻・担当仮名のみ。客の健康情報は持たない）
- Claude＝開発時の事実抽出（人が検証）・実行時の名寄せ・記録下書き・自己検査。数値換算・差分・8成分判定・手順書順はコード
- スライドは1画面1メッセージ（テンプレ感を嫌う）

## Don't
- 医療アドバイス／症状→OTC推奨／効く・量が多い＝効く／おすすめ・代わりにこれ
- 緑赤の良し悪し色、量順ソート、販売可ボタン
- MedNavi・道場の再利用、客向けモード
- 客の健康PII保存
- 「病気がわかる」「診断できる」等、医療機器（SaMD）該当を思わせる説明・宣伝文言
- 添付文書の文言・PDFの公開再配布、一括クロール、実行時の自動取得（PMDAはリンクアウト）
- 製品画像の取得・保管
