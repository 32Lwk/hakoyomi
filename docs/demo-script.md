# デモ動画 台本（T603、L-20261104-14）

- 尺：**180秒以内**（YouTube 限定公開、または Loom）
- 語り：ゆう本人（登録販売者）。1秒あたり約6文字で読むと、ナレーションは合計で約800字
- 画面：スマホ実機（375px）を主にし、PC の録画は Playwright で補う
- ルール：会期中に作った機能だけを映す。お客様役の顔・氏名は出さない。実商品は表示するが、良し悪しを言わない
- 言わない言葉：おすすめ／効く／代わりに／安心／大丈夫／飲めます。「答えを出す」ではなく「根拠をそろえる」と言う

凡例：✅ 実装済み（収録前に画面で確認） / ⚠️ 未実装・要判断 / 🎬 Remotion などで作る素材
