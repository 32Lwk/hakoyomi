# デモ動画 台本（T603、L-20261104-24 で全面改訂）

- 尺：**171秒**（180秒以内。YouTube 限定公開、または Loom）
- 軸（prd §1）：**誰が接客しても、お客様が同じ水準の説明を受けられる。ベテランでないと戸惑う確認（ドーピング・ハラール・授乳・運転…）にも、新人が自信を持って答えられる＝年数の壁をなくす**
- 語り：ゆう本人（登録販売者）。画面：スマホ（390×844）の画面収録＋実写（Gemini 生成・無音・人物は架空）
- 言う：「箱の細かい文字の情報」「厚労省・PMDA など国の機関の情報」「確認の材料」。言わない：おすすめ／効く／代わりに／安心／大丈夫／飲めます、添付文書の本文を表示する、RAG、琥珀色、段階表示の件数
- 実装：画面は localhost:3105 の最新UI（L-20261104-22 まで）で録画。本番更新後に撮り直し
