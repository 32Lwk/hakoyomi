# Design — ハコよみ

改訂 2026-11-02（L-20261102-32）：prd v2.0 に合わせて全面改訂。v1.x の「全部を1枚の縦画面に並べる」設計はモックで使いづらいと判断して破棄し、**場面ごとに画面を分ける**。

## 1. Audience & Context
- 登録販売者。明るい店内、レジ横や売場、片手、列待ち。お客様には画面を見せず、登販が口で伝える（必要なら根拠の画面を見せる）。
- 起点は**お客様が持ってきた箱の JAN**、または**お客様の質問**。
- 使う時間は1回数秒〜十数秒。迷わせない。

## 2. 画面構成（下部タブ4つ＋常設の読取ボタン）
```
┌ ヘッダ：ハコよみ（デモ表示のみ。常時の固定文言は置かない、L-20261103-04）
├ 本文（タブごと）
└ 下部：［商品］［質問］［●探す］［棚］［設定］（L-20261103-43。商品＝読んだ商品＋比べる、探す＝JANを読む・品名・成分の検索・種類・絞り込み。塗りつぶしの紺の丸は中央の探すだけで、今いるタブは紺の枠＋薄い紺の正円、文字は紺の太字（L-20261104-03）。探す画面で中央をもう一度押すとカメラ）
```
| タブ | 場面 | 中身 |
|---|---|---|
| 探す（既定・中央） | 箱を渡されて「これってどう？」／「鼻水に使えるもの」「眠くならないもの」 | 検索欄（左に JAN ボタン、L-20261104-21。品名・メーカー・成分、逆引きも）→ 種類／成分／含まないのシート → 何も入れていないときは種類のタイル、入れたら順位なしの一覧 |
| 商品 | 読んだ商品の説明と「これとこれ、何が違う？」 | 選んでいる商品（番号つき、4品まで）→【商品ごと】商品カード（品名 → 1日最大・服用間隔・内容量 → 確認ポイント → 用法・用量の表：年齢・1回量・1日の回数の値だけ、L-20261104-22。年齢は確認ポイントのバッジにも）＋操作バー（この商品について質問／棚で見る）／【比べる】2〜4品の表（列の見出しは画面上に残る、違う行だけ強調） |
| 質問 | 「運転について書いてある？」「何歳から？」 | 最初の画面（L-20261104-05/06）：上に見出しと写真つきの商品の格子（品名順、入力欄に打つと絞る）、入力欄（左に JAN）は下に固定。商品を選ぶか質問を送るとチャット（L-20261104-01/02）：上にやりとり（回答＝太字の結論→商品ごとの行（写真・品名・項目のタグ・詳しい説明。商品がなければ要点）→続けて聞く→出典（閉じる）。比べる質問で2品以上なら、商品ごとの行の代わりに違う行だけの表（コード）と表から作った結論。「新しい会話をはじめる」はヘッダー右上（質問の画面だけ「デモ・店舗は架空」と入れ替え。L-20261104-04/09））、下に入力欄（左に JAN、枠の中に話題の商品の画像つきバッジ）。品名で合う商品・選んでいる商品は入力欄の上に並べ、押すと話題になる。話題がなければ通知・手引き全体から |
| 棚 | 「それどこ？」 | 店内マップ＋棚の正面図。選んだ商品をハイライト |
| 設定 | 店頭の準備・確認 | 文字の大きさ／選んでいる商品をすべて外す／出典とデータの状態／このアプリについて |

- 読んだ商品は「商品」に自動で積まれる（最大4品）。2品から【比べる】に切り替えられる。
- 指定濫用防止の対象商品を読んだら、「読む」タブの上部に**確認・記録の帯**を出す（P1、M7）。
- PC は2カラム（左：読取・検索、右：結果）。同じ URL。

## 3. バッジ（M1）
- 1行に横並び、折り返し可。1つのバッジ＝アイコン＋短い語（例「運転注意」「授乳」「年齢 15歳から」「カフェイン 100mg」「濫用防止 対象」「ドーピング禁止成分」）。種類ごとに「何のバッジか」の1行説明を持ち、根拠シートの先頭に出す（L-20261103-10）。
- タップで根拠シートを開く：通知の薬効群・項目・記載条件（どの成分が条件に当たったか）、または成分と分量、禁止表の年版。最後に「実際の添付文書は PMDA で確認」。
- 色は良し悪しを表さない。種類で分ける：
  - 制度（指定濫用防止・リスク区分）：濃紺の枠
  - 通知の注意（運転・授乳・年齢・飲酒など）：濃グレーの塗り＋白文字
  - 成分の有無（カフェイン・ドーピング禁止成分など）：白地＋濃グレー枠
- 該当しないものはバッジを出さない（「眠気なし」のような安心させる表示はしない）。

## 4. Color
- ベースは白／濃グレー文字。**比較の強調は「違う」の1色のみ**（琥珀 `#F5B700`、背景は薄い琥珀 `#FFF4CC`）。
- 濃紺 `#1E3A5F`：制度バッジ、主ボタン、選択中のタブ。
- 緑・赤の良し悪し色は使わない。不確実な値はグレー＋「添付文書で確認」。

## 5. Typography & Interaction
- 数値はスマホで 20px 以上。タップ領域 44px 以上。
- JAN 読取は下部中央の1タップ。読めなければその場で手入力欄にフォーカス。
- 質問欄：よく聞かれる質問のチップ（「授乳中は？」「何歳から？」「眠くなる？」「一緒に飲めない薬は？」）＋自由入力。回答は抜き出した文を引用ブロックで出し、すぐ下に出典。
- さがす：結果は五十音順。上に「この中から選ぶのは販売者です」。
- 棚：店内マップは売場ブロックの簡略図、該当棚を濃紺で塗る。正面図は段×列のグリッドで該当位置を琥珀でハイライト。

## 6. States
| 状態 | 表示 |
|---|---|
| 空 | 「JANを読むか、品名で検索してください」 |
| 読取中 | カメラプレビュー＋「JANを枠に合わせてください」。手入力リンク常設。映像は保存・送信しない |
| 未登録JAN | 「このJANはデモデータにありません。品名で検索／入力し直す」 |
| 回答作成中 | エージェントの段階を表示（解釈→検索→照合→出典確認→チェック） |
| 根拠なし | 「該当する記載が見つかりません。添付文書（PMDA）で確認してください」 |
| ガード差し止め | 「表示できない表現が含まれたため省略しました」 |
| 不確実 | グレー＋「添付文書で確認」＋PMDAリンク |
| 記録完了 | 「確認済み 21:41」（判定表現なし） |

## 7. Tone
業務的・事実のみ。励まし・絵文字なし。判定・推薦の表現を出さない（常時の「判断は販売者」表示は L-20261103-04 で廃止）。

## 8. Source Labels
- 通知由来：「厚労省通知『使用上の注意』かぜ薬 してはいけないこと 3（記載条件：抗ヒスタミン剤を含有）」
- 商品事実：「成分・分量（入力：ゆう、確認日 2026-11-0X、出典 PMDA 添付文書 改訂 20XX-XX）」
- 禁止表：「WADA 禁止表 2026年版（JADA）」
- 担当者・手順書・店舗・棚が模擬であることを画面上で明示。

## 9. Demo 配慮
実商品名は表示するが、特定の商品を良く／悪く見せる表現・配色はしない。比較・検索結果を量順に並べ替えない。
