# Design — ハコヨミ

## 1. Audience & Context
- 登録販売者。明るい店内、レジ横、片手、列待ち。客には画面を見せず登販が口で伝える。
- 起点は**箱**（症状ではない）。これまでの検討（box-start）を維持。

## 2. Layout（単一縦画面）
```
┌ ヘッダ：ハコヨミ【仮】 | 判断は販売者が行ってください（常時）
├ 上段：2箱の違い（基準揃え表。違う行だけ強調）
├ 中段：原文並記（効能欄／してはいけないこと） A｜B
├ 下段：指定濫用防止 帯（対象/非対象・根拠成分・個数→複数）
│       確認項目チェック（手順書順）→［確認を記録］
│       棚カード（棚番・段）
└ 下端固定：［箱Aを撮る］［箱Bを撮る］［アップロード］ 個数 −/+
```
- スマホで差と確認項目までスクロール最小。PCは2カラム（左：写真、右：結果）。

## 3. Color
- ベースは白/濃グレー文字。**強調は「違う」の1色のみ**（例：琥珀 `#F5B700` 背景薄）。
- 緑/赤の良し悪し色は使わない。濫用帯は中立色（濃紺枠）。
- 不確実値：グレー＋「箱で確認」。

## 4. Typography & Interaction
- 数値は大きく（スマホ 20px以上）、行高タップ領域44px以上。
- 値タップ→箱写真の該当bboxをクロップ拡大（PhotoZoom）。
- 撮影ボタンは下端、1タップ。

## 5. States
| 状態 | 表示 |
|---|---|
| 空 | 「箱Aと箱Bの裏面を撮ってください」 |
| 抽出中 | スケルトン＋箱ごとの進捗（A/B並列）。区分判定が出たら先に帯を表示 |
| 不確実 | グレー＋「箱で確認」＋再撮影リンク |
| ガード差し止め | 「表示できない文言が含まれたため省略しました」 |
| エラー | 「読み取れませんでした。もう一度撮る／アップロード」 |
| 記録完了 | 「確認済み 21:41」（判定表現なし） |

## 6. Responsive
スマホ主、PCデモ副。どちらも同一URL。PCはドラッグ&ドロップでアップロード可。

## 7. Tone
業務的・事実のみ。ウェルネス調・励まし・絵文字なし。「判断は販売者が行ってください」を常時表示。症状入力はどこにもない。

## 8. Demo配慮
差の行を量順に並べ替えない。実商品名の大写しは運営確認後（それまで「かぜ薬A／B」）【仮】。
