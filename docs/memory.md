## Glossary
- **登録販売者**：第2類・第3類の一般用医薬品を販売できる専門家。判断はこの人が行う
- **指定濫用防止医薬品**（2026-05-01適用、通知原文で確認済み L-20261102-29）
  - 根拠：令和7年法律第37号（改正薬機法）第36条の11第1項。成分＝令和8年厚生労働省告示第32号（適用通知：令和8年2月13日 医薬発0213第1号）。数量＝令和8年厚生労働省告示第33号（適用通知：医薬発0213第2号）。販売等＝令和7年12月26日 医薬発1226第16号。通知の掲載元：富山県 https://www.pref.toyama.jp/1208/kusuri/20260501.html
  - 8成分（その水和物・塩類を含む。いずれも外用剤を除く）：エフェドリン、コデイン、ジヒドロコデイン、ジフェンヒドラミン、デキストロメトルファン、プソイドエフェドリン、ブロモバレリル尿素、メチルエフェドリン
  - 対象外：生薬を主たる有効成分とする製剤（例：マオウ含有の漢方）。ジヒドロコデインセキサノール等は対象
  - 外用剤：口腔用錠剤（トローチ等）・吸入剤・点眼・点耳・点鼻・坐剤・膣錠・軟膏/貼付剤など
  - 数量（1包装あたり）：基本5日分。7日分になる例外＝ジヒドロコデイン・ジフェンヒドラミン・デキストロメトルファン（かぜ薬の効能あり）、プソイドエフェドリン・メチルエフェドリン（かぜ薬または鼻炎用内服薬の効能あり）、ブロモバレリル尿素（解熱鎮痛薬の効能あり）。エフェドリン・コデインは例外なし。年齢で用量が違えば1日量が最大の年齢で、頓用は1日最大量で判断。超えるものが「大容量製品」
  - 複数個：同じ指定成分を含む別製品を1つずつ売る場合も複数個に当たる（医薬発1226第16号 第4-1(5)）
  - 販売時の確認事項（同 第4-1(4)）：ア 年齢／イ 他の薬剤・医薬品の使用状況／ウ 18歳未満なら氏名／エ 当該製品と他の指定濫用防止医薬品の購入・譲受け状況／オ 大容量製品または複数個ならその理由／カ 適正使用の確認に必要な事項／キ その他情報提供に必要な事項
  - 18歳未満・大容量または複数個（18歳以上）は対面等（リアルタイムの映像・音声を含む）で情報提供。18歳未満への大容量・複数個の販売不可は自治体・業界団体資料の記載（法令本文は未確認）
- **JAN**：商品バーコード番号。マスタ照合・棚引きに使う
- **自店手順書**：指定濫用防止医薬品の販売等手順書。店が作成・運用義務。MVPは模擬【仮】
