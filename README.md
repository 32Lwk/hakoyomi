# ハコよみ

ドラッグストアの**登録販売者**向けの店頭業務支援アプリです（Built with Claude Japan 2026 出品作品）。お客様向けのアプリではありません。

JAN読取（または手入力・品名検索）で商品を特定し、公開情報にもとづく比較・確認の材料をそろえます。

- 2商品の成分・分量を基準をそろえて並べ、違う行だけを示す
- 効能・「してはいけないこと」などの文言は表示せず、PMDA の添付文書へリンク（要約・言い換えもしない）
- 指定濫用防止医薬品の確認項目を手順書の順に提示し、確認した事実の記録を支援
- 販売記録の下書き作成を支援
- 自店の棚番・段を表示

## 判断は販売者が行ってください（HITL）

アプリは材料をそろえるだけです。最終判断・説明は常に登録販売者が行います。画面には「判断は販売者が行ってください」を常時表示します。判定ボタンや自動判定はありません。

## やらないこと

- 症状の入力、個人の病状・受診・販売可否の判定
- 特定の薬・商品のおすすめや推奨
- お客様の氏名・健康情報の保存
- 添付文書の文言・PDF の公開・再配布、一括クロール、PMDA への自動アクセス

## データ方針

- デモ商品は実在の市販薬（大手ブランドを中心に約20品、`src/data/demoSkus.json`）です。表示するのは品名・メーカー・JAN・リスク区分・成分名・分量・内容量などの**事実**と、パッケージ写真です
- **効能・効果、用法・用量、使用上の注意など商品固有の文面は、アプリに載せていません。「引用＋PMDAリンク」の方針で、各商品から PMDA の添付文書ページへリンクします。添付文書の全文を再配布するものではありません。** 通知由来の記載事項（厚生労働省「使用上の注意」）は、成分から導いたものとして出典つきで示します
- 事実は、開発者が手作業で入手・撮影した既存のデータ資産（運営の回答により利用可）から必要な品だけを取り出し、分量・内容量・JAN は公開情報（メーカー公式など）で補いました。開発者が実物の箱で確認するまで、画面には「未確認」と表示します。カタログの全件はリポジトリに含めません
- 禁止表（ドーピング）の区分は既存データの値で、年版は確認中です。最終確認は Global DRO 等で行ってください
- パッケージ写真は `images.yutok.dev` から表示します（`src/lib/packageImage.ts` の `PACKAGE_PHOTOS` を false にすると、薬の種類のイメージ図に切り替わります）
- お客様・担当者・手順書・棚は模擬データです。実在のお客様情報・勤務先の資料は使いません

デモSKUの作り直し（開発時のみ。入力ファイルはリポジトリの外に置く）：

```bash
python3 -I scripts/demo/build_demo_skus.py <otc_medicines_integrated.csv> <r2_medicine_image_urls.json> src/data/demoSkus.json <research.json> [...]
```

## 開発

```bash
cp .env.example .env.local   # 値はサーバー専用。NEXT_PUBLIC_ にしない
npm install
npm run dev                  # http://localhost:3000
```

設計の正本は `docs/`（`prd.md` / `rules.md` / `design.md` / `architecture.md` / `tasks.md`、台帳 `LEDGER.md`）です。

スタック：Next.js（App Router）+ TypeScript + Tailwind CSS / Supabase / Vercel / Claude API
