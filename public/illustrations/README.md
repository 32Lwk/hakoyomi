# 薬の種類イラスト

実在の商品を描いたものではなく、**薬の種類を表すイメージ図**です（L-20261102-33）。画面に出すときは「イメージ図」と明示してください。製品写真の代わりに、一覧・比較・検索の目印として使います。

- ファイル名：`{kind}-{pattern}.svg`（viewBox 100×100、12種×11パターン＝132点、さらにパッケージ6形に描き分け v2〜v5 が288点）
- 種類名と色：`index.json`
- 作り直し：`node scripts/gen-illustrations.mjs`（SVG は手で編集せず、このスクリプトを直す）

| pattern   | 形                                              | 向いている場所                 |
| --------- | ----------------------------------------------- | ------------------------------ |
| `box`     | パッケージ（箱＋種類名＋モチーフ）              | 商品カード・一覧のサムネイル   |
| `form`    | 剤形（錠剤・PTPシート・瓶・カプセル・容器など） | 比較表の見出し・小さい表示     |
| `symbol`  | 丸い背景＋モチーフ                              | 検索の絞り込み・分類アイコン   |
| `box2`    | 横長の箱（下の帯に種類名＋2つめのモチーフ）     | 同じ種類が並ぶ一覧での描き分け |
| `form2`   | 2つめの剤形（顆粒・瓶・カプセル・容器など）     | 比較表で同じ種類が並ぶとき     |
| `symbol2` | 丸い背景＋2つめのモチーフ                       | 分類アイコンの描き分け         |
| `duo`     | 剤形＋右下に小さなシンボル                      | 種類と剤形を一度に見せたいとき |
| `slim`    | 縦長スリム箱（斜めの帯＋剤形）                  | 一覧のサムネイルの描き分け     |
| `square`  | 正方形の箱（色の面＋丸窓に2つめのモチーフ）     | 一覧のサムネイルの描き分け     |
| `pouch`   | スタンドパウチ（袋入りの顆粒・錠剤のイメージ）  | 一覧のサムネイルの描き分け     |
| `carton`  | フタの開いた箱から2つめの剤形がのぞく           | 商品カードの見出し             |

同じ種類の商品が並ぶときは、`box`/`box2`/`slim`/`square`/`pouch`/`carton`、`form`/`form2`、`symbol`/`symbol2` を交互に使うと見分けやすくなります（L-20261102-35）。

| kind       | 種類       | kind      | 種類         |
| ---------- | ---------- | --------- | ------------ |
| `cold`     | かぜ薬     | `eye`     | 目薬         |
| `fever`    | 解熱鎮痛薬 | `topical` | 外用薬       |
| `cough`    | せき止め   | `vitamin` | ビタミン剤   |
| `rhinitis` | 鼻炎薬     | `sleep`   | 睡眠改善薬   |
| `nasal`    | 点鼻薬     | `kampo`   | 漢方薬       |
| `stomach`  | 胃腸薬     | `motion`  | 乗り物酔い薬 |

```tsx
<img src="/illustrations/cold-box.svg" alt="かぜ薬のイメージ図" width={96} height={96} />
```

## 同じ形の描き分け（パッケージのみ、L-20261102-37）

`box` `box2` `slim` `square` `pouch` `carton` には、形・モチーフ・種類の色はそのままで少しだけ違う版があります。同じ種類・同じ形の商品が並ぶときに使い分けます。

| ファイル                  | 違い                           |
| ------------------------- | ------------------------------ |
| `{kind}-{pattern}.svg`    | v1 基本                        |
| `{kind}-{pattern}-v2.svg` | 濃い色                         |
| `{kind}-{pattern}-v3.svg` | 正面に斜めストライプ           |
| `{kind}-{pattern}-v4.svg` | 正面にドット                   |
| `{kind}-{pattern}-v5.svg` | 生成り（白地と上面を薄い色に） |

```ts
illustrationSrc("cold", "box", 3); // → /illustrations/cold-box-v3.svg
```
