# 薬の種類イラスト

実在の商品を描いたものではなく、**薬の種類を表すイメージ図**です（L-20261102-33）。画面に出すときは「イメージ図」と明示してください。製品写真の代わりに、一覧・比較・検索の目印として使います。

- ファイル名：`{kind}-{pattern}.svg`（viewBox 100×100、12種×3パターン＝36点）
- 種類名と色：`index.json`
- 作り直し：`node scripts/gen-illustrations.mjs`（SVG は手で編集せず、このスクリプトを直す）

| pattern  | 形                                              | 向いている場所               |
| -------- | ----------------------------------------------- | ---------------------------- |
| `box`    | パッケージ（箱＋種類名＋モチーフ）              | 商品カード・一覧のサムネイル |
| `form`   | 剤形（錠剤・PTPシート・瓶・カプセル・容器など） | 比較表の見出し・小さい表示   |
| `symbol` | 丸い背景＋モチーフ                              | 検索の絞り込み・分類アイコン |

| kind       | 種類       | kind      | 種類         |
| ---------- | ---------- | --------- | ------------ |
| `cold`     | かぜ薬     | `eye`     | 目薬         |
| `fever`    | 解熱鎮痛薬 | `topical` | 外用薬       |
| `cough`    | せき止め   | `vitamin` | ビタミン剤   |
| `rhinitis` | 鼻炎薬     | `sleep`   | 睡眠改善薬   |
| `nasal`    | 点鼻薬     | `kampo`   | 漢方薬       |
| `stomach`  | 胃腸薬     | `motion`  | 乗り物酔い薬 |
