# デモ動画の画面録画（T603、L-20261104-19）

台本 `docs/demo-script.md` の S2〜S6（アプリの画面）を Playwright で録る。1場面＝1本の webm。
アプリの依存とは分けている（この folder だけの package.json、`playwright` 1.64.1 のみ）。

## 録り方

```sh
cd hakoyomi/video/record
npm install
npx playwright install chromium

# 本番（既定 BASE_URL=https://hakoyomi.yutok.dev）で全場面
node record.mjs
# 手元の dev サーバーで、または場面を選んで
BASE_URL=http://localhost:3105 node record.mjs
BASE_URL=http://localhost:3105 node record.mjs s4 s45
```

- 出力：`out/<場面>.webm`（780×1688＝390×844 の2倍、VP9、音なし）と `out/<場面>.cues.json`（何秒目に何が映ったか。ナレーション合わせ用）。最後に各本の秒数を出す
- ほかの切り替え：`SHOTS=1`（目印ごとに静止画を `out/shots/` に残す）、`TAP=0`（押した場所の紺の丸を出さない）、`SPEED=0.5`（間を半分に。確かめるとき用）、`HEADED=1`（画面を出して動かす）、`S3_SET=script`（S3 を台本の例の3品で録る）、`S5_PICK=品名`（S5 で一覧から選ぶ商品）
- 要るもの：Node 20 以上、ffmpeg／ffprobe（最初の空白の切り落としと秒数。ない場合は切らずに置き、`cues.json` の `leadIn` に切る秒数を書く）
- S6 は本物の Supabase にメモを保存する。録り終えたら（途中で失敗しても）作ったメモを `DELETE /api/memos/{id}` で消す。デモ用の3件（`00000000-0000-4000-8000-00000000040x`）は消さない

### 画面の作り
- 390×844・deviceScaleFactor 2・日本語（ja-JP、Asia/Tokyo）・明るい表示。ヘッドレスの画面録画は deviceScaleFactor を無視して1倍で左上に小さく撮るため、ブラウザを `--force-device-scale-factor=2` で起動している（これで枠いっぱいの2倍になる）
- 最初のページが描けるまで（about:blank の白）を切り落としている。どの本も1フレーム目から枠いっぱい
- 人の操作に見えるように：押す前後に間、1字ずつの入力（80〜200ms）、結果の後に読む時間（2.5〜4秒）。押した場所には薄い紺の丸を出す（画面録画にはマウスが映らないため）
- 選ぶときは役割・表示の文字（アクセシビリティ）で探す。Claude の回答は40秒まで待つ

## 台本（demo-script.md）と画面のずれ

1. **S2 カメラ**：ヘッドレスではカメラが使えず、読み取りシートに「カメラを使えません。JANを入力するか、品名で検索してください」が出る。カメラで読む絵はスマホ実機で撮り、この録画は「商品カードが出たところ」から使うのがよい
2. **S2 バッジ**：台本「濫用防止 対象・運転注意・授乳・年齢」のうち、年齢はバッジの列ではなく品名の下の大きな帯（「12歳から」）。ほかに「飲酒しない」が出る。ドーピング禁止成分のバッジは 2026-11-04 の録画の途中から出なくなった（L-20261104-18 で禁止表を更新中のためと思われる。本番で確かめる）
3. **S3 の3品**：台本の例（アレグラFX／アレジオン20／パブロン鼻炎速溶錠EX）は 18行すべてが「違う」になり、「琥珀色の行だけが目に入る」絵にならない。既定はアレグラFX／アレジオン20／ストナリニZジェル（7／11が違う）にした。台本の例で録るなら `S3_SET=script`。3品だと3列目が画面の右で切れる（横に送れる）
4. **S4 チップの文言**：台本「授乳中は？」→ 画面のチップは「授乳中について書いてある？」。ナレーションの「授乳中でも飲める？」はお客様の言葉として問題ないが、画面にその文はない
5. **S4 説明メモ**：回答の下に出るのはクロルフェニラミンマレイン酸塩のデモ用メモで、中身は運転の項目の話（授乳の答えの下に運転のメモが出る）。授乳の話に合わせたいなら、デモ用メモの文面を変えるか、S4 の質問を「運転について書いてある？」にする
6. **S4 段階表示**：段階は 2〜4 秒で流れきる。「照合」と「出典検証」はほぼ同時に出て、ガードは答えと同時に終わる（演出していないため）。件数をナレーションで読むなら、回答後の「どう答えたか」を映す方が読み取れる
7. **S4.5 例の答え**：台本「何歳から？」→「15歳から。」は、パブロンSゴールドW錠では「12歳から」になる。3問とも答えがある商品としてルルアタックNX を使った。答えの文は Claude なので回により少し変わる（1回目は「15歳未満の小児は服用しない」）。「聞けること」は最初の画面にしかないので、2・3問目は入力欄に打って送っている
8. **S5 含まない**：台本「抗ヒスタミン成分を外す」→ 画面の選択肢は「運転注意の成分を含まない」（ほかにカフェイン・指定濫用防止の対象外・ドーピング禁止成分）。抗ヒスタミン成分を名指しで外す項目はない
9. **S5 並び**：台本「五十音順」→ 画面は「品名順（順位ではありません）」。種類ごとの見出しで分かれる
10. **S5 鼻水の一覧**：「運転注意の成分を含まない」で残る15品にはかぜ薬（パイロンPL 等）と点鼻薬10品が入る。「鼻水に使えるもの」のナレーションで内服だけを見せたいなら、種類で鼻炎薬に絞る手順を足す
11. **S6 秒数**：枠17秒に対して、保存（Claude の自己検査）に約4秒、止まる方に約5秒かかる
